Receives every log message that passes the level check. Install one with set_log_sink() to forward FastCaloSim messages to another logging system, for example a framework's message service.

Function documentation

void FastCaloSim::LogSink::write(MSG::Level lvl, std::string_view file, int line, std::string_view text) pure virtual

One message: file and line locate the call site, text is the message as written at the call site, without decoration and without newlines at the end (newlines inside the text are kept). Called concurrently from all threads that log. An exception thrown here does not propagate: the message then goes to the default sink.
