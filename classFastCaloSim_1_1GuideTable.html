Guide table (Chen and Asau, 1974) for sampling from a cumulative distribution c[0..n-1] (non-decreasing) with a uniform random number u.

upper_bound(c, u) returns exactly what std::ranges::upper_bound returns (the index of the first element with u < c[i], or n), with a search over a few elements instead of all of c: the range of u is divided into 2^b equal buckets, one per 4 to 8 bins, and the table stores the result for the lower edge of every bucket. The result for a u inside a bucket lies between the results for the bucket's two edges, so only that part of c is searched, on average 4 to 8 elements. The bucket of u and its edges are powers of two apart and computed without rounding, so the result is the same as that of the full search for every u.

More buckets would make the search a little faster (one bucket per bin: about 1% of the whole simulation) but cost much more memory: the production parametrization has 3.8e8 bins in its 2D histograms.

Two kinds of cumulative distributions are supported:

  • float values in [0, 1], searched with a double u in [0, 1); for any other u (negative, >= 1, NaN) the full search is used
  • 32-bit unsigned integers, searched with an unsigned 32-bit u The table is built only for sorted c without NaN; otherwise, and when upper_bound() gets a c of another size than the table was built for, the full search is used, so the result is always that of the full search.

build() must be called whenever c changes; upper_bound() only reads the table and can be called from several threads.
